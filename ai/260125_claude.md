## Claude code 기본 슬래시 명령어

### 슬래시 명령어

- `/init` : `CALUDE.md` 파일을 생성 하거나 업데이트 하여 프로젝트의 규칙을 적용 한다.
- `/login`, `/logout` : 로그인 하거나 로그아웃 한다.
- `/stats` : 데일리 세션, 사용량, 연속적으로 사용한 내용을 시각화 하여 보여준다.
- `/clear` : 기존 대화를 초기화 하고 새로운 대화를 시작 한다.
- `/model` : AI 모델을 변경 할 때 사용 한다. (Haiku, Sonnet, Opus)
- `/compact [지침]` : 대화가 너무 길어지면 대화 큰 줄기는 유지 하면서 토큰을 절약 하기 위해 사용 한다.
- `/context` : 현재 컨텍스트를 얼마나 사용하고 있는지 보여준다
- `/memory` : 메모리 파일을 편집 한다
- `/agents` : 특정 작업 수행용 AI 서브 에이전트를 관리하거나 추가 한다.
- `/hooks` : 이벤트 훅 설정을 관리 한다.
- `/mcp` : MCP 서버 목록 및 설정을 관리 한다.
- `/plugin` : 클로드 플러그인을 관리 한다.
- `/todos` : 현재 TODO 항목을 보여 준다
- `/resume` : 이전에 진행 했던 대화 세션을 다시 불러올때 사용 한다. 
- `/export` : 현재 대화 세션을 파일이나 클립보드로 내보낸다.
- `/config` : 설정 에서 Config 탭을 연다.
- `/status` : 설정 에서 Status 탭을 연다.
- `/sandbox` : 파일, 네트워크들 이 격리된 샌드박스 모드에서 bash 를 활성화 한다.
- `/statusline` : 입력 상태 줄을 설정 한다.
- `/privacy-setting` : 개인 보호 정보 설정을 보거나 수정 한다.
- `/permissions` : 권한을 보거나 수정 한다.
- `/doctor` : Claude 상태를 점검 한다.
- `/ide` : IDE 도구와의 연동 상태를 본다.
- `/exit` : 완전히 종료 한다. 
- 코드리뷰
  - `/review` : 일반 코드 리뷰
  - `/security-review` : 보안 취약점 위주의 코드 리뷰

> 명령어가 기억 나지 않는 다면 `/help` 을 사용 해보자
